## Campus description — General introduction to AI / ML

Machine learning studies how computational systems infer useful models, rules or representations from data rather than having every decision explicitly programmed. This block introduces supervised and unsupervised learning, training and validation, loss functions, underfitting/overfitting, generalization and trainability. The Ising model is used as a running computational example because it connects statistical physics, optimization, probabilistic modelling and learning through one explicit energy landscape. Automata and dynamical systems provide complementary examples of rule-based models whose collective behaviour can be learned, simulated or classified.

## Campus description — Quantum Machine Learning

The QML block asks what changes when data, models or subroutines are represented quantum mechanically. We distinguish rigorous notions of quantum advantage from heuristic performance claims, and organize the field into quantum representations of classical problems, quantum-inspired methods, quantum optimization, learning from quantum data/experiments and hybrid variational approaches. Particular attention is paid to sample complexity, trainability, noise and data-loading costs: a quantum implementation is not automatically useful merely because it is quantum. The block ends by connecting these questions to the course practical, where classical and quantum Ising representations are compared through a contextual kernel.

## 1. What is learning?

A useful operational decomposition is:

~~~text
data / observations
-> representation
-> model class
-> objective / loss
-> training rule
-> validation / generalization
-> prediction or scientific inference
~~~

Core vocabulary:

- **supervised learning**: infer a map from labelled examples;
- **unsupervised learning**: identify structure without supplied labels;
- **training**: adjust model parameters to reduce an objective;
- **validation/test**: estimate behaviour away from the training sample;
- **generalization**: performance on unseen data from the relevant distribution;
- **trainability**: whether the optimization problem can be solved efficiently enough to obtain a useful model.

The introductory material uses linear regression, objective functions and under/over-fitting as concrete examples.

## 2. Learning as an algorithmic problem

A learning procedure requires:

~~~text
hypothesis class + data access + loss + optimizer + stopping rule + evaluation
~~~

In QML the resource model must also count state preparation, measurements, finite-shot estimation, data loading and classical optimization.

Relevant resources include runtime, gate depth, samples, state copies, measurements, memory, classical preprocessing/postprocessing and noise budget.

## 3. Generalization and learning theory

Learning theory studies which functions or probability distributions can be learned efficiently and how many resources are needed. The PAC viewpoint is enough for the course:

~~~text
probably      = success with high probability
approximately = small generalization error
correct       = relative to a declared target/task
~~~

In QML distinguish:

1. learning a classical object with a quantum computer;
2. learning from quantum data;
3. learning a quantum state, channel, Hamiltonian or Liouvillian;
4. learning a classical distribution generated by a quantum process.

## 4. The Ising model as the course spine

For the square-lattice classical Ising model:

~~~math
H(s)=-J\sum_{\langle i,j\rangle}s_i s_j,
\qquad s_i\in\{-1,+1\}.
~~~

It gives one common object for Physics, Mathematics and Computer Science:

| Physics | Mathematics | Computer science |
|---|---|---|
| phase transition, magnetization, correlations | graph/lattice structure, duality, symmetry | Monte Carlo, state representation, complexity |

The practical starts with **classical Metropolis sampling**. A duality transformation is not identified with a Monte Carlo update rule.

## 5. Hopfield as an Ising-like learning model

For binary neurons, a Hopfield model uses:

~~~math
E(s)=-\frac12 s^TWs.
~~~

This creates an energy-language bridge to Ising models while preserving the distinction between learned/dense Hopfield couplings and the geometrically fixed local couplings of the Onsager square lattice.

## 6. Classical → quantum representations

A minimal transverse-field Ising model is:

~~~math
H=-J\sum_i Z_iZ_{i+1}-h\sum_iX_i.
~~~

The pedagogical move is:

~~~text
classical bit/spin configuration
-> quantum state / observable representation
-> quantum measurement statistics
~~~

This is one example of re-quantization in the broad course sense: take a classical structure or task and ask which quantum representation is meaningful. Re-quantization is not itself evidence of advantage.

## 7. What counts as quantum advantage?

The course distinguishes:

- **complexity-theoretic advantage**;
- **query/sample advantage**;
- **practical end-to-end advantage**;
- **scientific/inference advantage**.

Every QML comparison should state:

~~~text
input model
data loading
precision
training cost
measurement cost
classical baseline
hardware/noise assumptions
~~~

A fast internal quantum subroutine does not imply an end-to-end advantage when data loading or measurement dominates.

## 8. Quantum-inspired, quantum optimization and hybrid QML

### Quantum-inspired

Classical algorithms may borrow tensor, kernel, sampling or amplitude-like structures associated with quantum methods.

~~~text
quantum-inspired != quantum execution
~~~

### Quantum optimization

Ising/QUBO mappings, annealing-inspired methods and variational optimization belong here.

~~~text
optimization formulation != learning task
~~~

### Hybrid variational algorithms

Typical NISQ loop:

~~~text
parameterized quantum circuit
-> measurements / cost
-> classical optimizer
-> parameter update
-> repeat
~~~

This motivates QNNs and variational QML, but also introduces finite-shot noise and trainability constraints.

## 9. Trainability and limits

Questions:

- Are gradients informative?
- Does measurement cost scale reasonably?
- Is the model expressive but still trainable?
- Does noise erase the signal?
- Is the encoding compatible with the data?
- Is a classical model already competitive?

Expected conclusion:

~~~text
quantum advantage is a claim that must be operationalized and tested.
~~~
