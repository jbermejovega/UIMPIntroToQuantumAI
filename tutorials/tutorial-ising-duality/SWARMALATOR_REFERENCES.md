# Swarmalator references used by the 2026 codebook

This bibliography supports the JARANIAN_JAURIA teaching facet. The codebook
uses the models as scientific references and keeps the SIGIL/QUNO vocabulary as
a separate pedagogical projection.

   *Nature Communications* **8** (2017), 1504.

   a ring", *Physical Review E* **105** (2022), 014211.

## Teaching scope

The following are deliberately kept distinct in the codebook:

```text
Kuramoto synchronization
!= circle-map mode locking
!= 1D swarmalator ring
!= 2D swarmalator aggregation/synchronization
!= Ising ordering
!= Anderson/Aubry-André localization
```

They may share observables, transformations or interface patterns without
becoming the same physical model.
